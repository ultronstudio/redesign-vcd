# VČD redesign

Směr:

- inspirace typem UX, který používají moderní ticketing/event weby:
  velké eventové fotografie, hledání představení, filtrování a přímý prodej,
- nejde o kopii Colosseum Ticket; barevnost, layout, hierarchie a sekce jsou vlastní,
- identita VČD je zachována přes logo, vínovou červenou, reálné inscenace a fotografie,
- žádné eyebrow texty, obří dekorativní nápisy, ghost texty nebo agenturní landing-page prvky,
- hlavní cesta návštěvníka: vyhledat představení -> zobrazit detail -> koupit vstupenku,
- dark UI jen tam, kde podporuje fotografický obsah a kulturní charakter.

Použito:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Inter + Roboto Slab
- vanilla JavaScript

Fotografie a logo používají veřejné URL Východočeského divadla Pardubice.


Úprava barev:

- paleta je omezená na vínově červenou VČD, černou, tmavé neutrály, bílou a šedou,
- fallback plochy při nenačtení fotografie jsou černé/tmavé, ne hnědé,
- newsletter používá tmavou vínovou.
